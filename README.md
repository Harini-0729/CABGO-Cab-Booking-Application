CABGO – Cab Booking Application

1. Project Overview

CABGO is a cab booking application that allows users to book rides conveniently and view their booking details.

2. Objectives

- Make cab booking simple and user-friendly.
- Allow users to enter pickup and drop locations.
- Display estimated fare details.
- Provide booking confirmation.

3. Main Features

- User registration and login
- Pickup and drop location entry
- Cab selection
- Fare estimation
- Ride booking and confirmation
- Booking history

4. Users

- Customer
- Driver
- Administrator

5. Development Methodology

Agile Scrum is used to develop the application through short iterations called sprints.

6. Functional Requirements

1. FR01 – User Registration: The system shall allow users to register and log in using valid credentials.
2. FR02 – Location Entry: The system shall allow users to enter pickup and drop locations.
3. FR03 – Cab Selection: The system shall allow users to select an available cab.
4. FR04 – Fare Estimation: The system shall calculate and display the estimated fare.
5. FR05 – Ride Booking: The system shall confirm bookings and allow users to view booking history.

7. Non-Functional Requirements

1. NFR01 – Performance: The system should respond within 3 seconds under normal conditions.
2. NFR02 – Security: The system shall protect user credentials and personal information.
3. NFR03 – Usability: The interface shall be simple and user-friendly.
4. NFR04 – Reliability: The system shall process valid bookings correctly and prevent duplicate submissions.
5. NFR05 – Availability: The system should target 99% availability, excluding scheduled maintenance.
